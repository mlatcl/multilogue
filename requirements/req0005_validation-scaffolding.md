# REQ-0005: Validation scaffolding without study-specific coding schemes

## Description

Multilogue provides agreement helpers (κ, rank agreement), sampling utilities for blind checking sheets, and an evidence-pack HTML shell. Grounds taxonomies, experience word lists, and study prompts remain in consumers.

**Why this matters**: Validation process is shared; coding schemes are not.

**Who benefits**: Authors building validation playbooks for non-coder reviewers.

## Acceptance Criteria

- [ ] κ and rank-agreement helpers available
- [ ] Sheet sampling helper that stratified samples by configurable columns
- [ ] Evidence-pack writer that accepts a generic phrase table and grouping columns
- [ ] No grounds/experience taxonomy shipped in multilogue
