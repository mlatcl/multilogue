## Summary

Add `multilogue.access` modelled on [pods](https://github.com/lawrennd/ods) (`pods.datasets.<name>()` + shared download/cache helpers): a JSON resource registry, cache under a configurable data path, licence prompt, and one loader per public source that returns `units` plus metadata. Users switch sources with `load("polis", ...)` / `list_sources()`.

**Requirements:** REQ-0001 (Unit contract), REQ-0006 (switchable open corpora).

## Motivation

Synthetic validation covers the pipeline; public civic dumps let us exercise Access→Address on real consultation-style text without putting private dialogue data in the repo. Pods already solved “pick a dataset by name, download once, cache locally.”

## Detailed Description

### API

```python
from multilogue.access import load, list_sources, clear_cache

print(list_sources())
bundle = load("polis", conversation="vtaiwan.uberx")  # or load("synthetic")
units = bundle["units"]  # list[Unit]
# bundle also has citation, license, details, path, source
```

Equivalent named entry points: `multilogue.access.datasets.polis(...)`, `.gdn_cc(...)`, `.cdcp(...)`, `.cimt(...)`, `.decidim(...)`, `.synthetic(...)`.

### Cache and licence

- Default cache: `MULTILOGUE_DATAPATH` or `~/.cache/multilogue/<source>/`
- `override_manual_authorize = True` or env `MULTILOGUE_ACCESS_YES=1` skips interactive licence prompts (tests/CI)
- Never commit cache contents; `data/` remains gitignored

### Initial sources

| Name | Remote | Unit mapping |
|------|--------|--------------|
| `synthetic` | in-memory | existing `make_units` |
| `polis` | compdemocracy/openData | comment-body → unit |
| `gdn_cc` | Hugging Face LequeuISIR/GDN-CC | au_text / opinion_text → unit |
| `cdcp` | Richmond CDCP zip | `.txt` comment → unit |
| `cimt` | GitHub CIMT argument corpus | sentence content → unit |
| `decidim` | Metadecidim open-data CSV | proposal/comment body → unit |

Heavy or gated sources (MeetingBank NC, OpenGov HF gate) are documented but not required for the first cut.

### Boundaries

Still no PDF/`.docx` study parsers. Open-data CSV/JSON/TSV→Unit adapters are Access helpers for public corpora only.
