# CIP-0003: Pedagogical Colab notebooks with diagnostic plots

- [x] Proposed

- [x] In Progress

## Summary

Add a generated notebook series (`00`–`07`) that teaches multilogue's Access → Assess → Address method on synthetic (and optional public) data, with Colab badges, diagnostic plots in `multilogue.viz`, and offline smoke tests.

## Motivation

The package needs a readable path into the method — not only pytest. Notebooks should explain *why* design choices exist (unit contract, assess-without-question, frozen assignments, document weighting, multiverse callbacks) using public or generated data.

## Detailed Description

- Builder: `scripts/build_notebooks.py` (source of truth)
- Plots: `multilogue.viz` (matplotlib; `[report]` / `[dev]`)
- Bootstrap: `multilogue.notebook.setup`
- Colab: public `mlatcl/multilogue` install; FakeClient default
- No private dialogue corpora; no references to sibling study packages in notebook prose
