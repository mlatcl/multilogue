## Summary

Extend question-agnostic Assess text diagnostics (unit, sentence, word-length,
character inventory + flags/histograms), teach them in notebook 01, explain
extract LLM calls and phrase embedding in notebook 02, and insert an Assess
gate plus Address stage prose into notebook 09. Primary source remains
`scripts/build_notebooks.py`.

**Which requirements?** REQ-0009.

## Motivation

Notebook 09 jumped Access → Gold ℓ → Address with only a thin
`unit_size_table(...).describe()`. Assess helpers covered little beyond word
counts. Address ran as a StageRunner black box with no pedagogical account of
what extract prompts return or how phrases become embedding vectors. Analysts
could not see whether paragraphs, sentences, word lengths, or character use
looked sane before paying for LLM calls.

## Detailed Description

### Library (`assess_base` + `viz`)

Additive helpers (no LLM, no research-question filters):

1. Unit length bands / percentile summary on existing `unit_size_table`
2. Sentence-length tables (heuristic split) + extreme flags
3. Word-length distribution with `lang` in `{de, en, auto}`
4. Character-class inventory + unusual codepoint sample + flags
5. Matching histograms / bar charts in `viz`

### Notebooks (via builder)

- **01**: expand Diagnostics with the new tables and plots
- **02**: methodological cells on extract LLM I/O and `Embedder`
- **09**: Assess stage between Access and Gold ℓ; Address prose for stages 4a–4e

### Out of scope

- Changing CIMT / PDF paragraphisation (Access follow-on if flags light up)
- Adding `langdetect` or heavy NLP dependencies
- Live LLM calls solely for pedagogy (FakeClient + prose)

## Implementation Plan
