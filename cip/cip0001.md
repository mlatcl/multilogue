## Summary

Create the installable `multilogue` package that holds the reusable Access → Assess → Address methodology shared by `ai-dialogue-formats` and `pub-dialogue`. Fynesse informs AAA boundaries philosophically; there is no runtime dependency on fynesse.

**Requirements addressed:** REQ-0001 … REQ-0005.

## Motivation

Both papers reimplemented StageRunner-style checkpoints, extract→embed→cluster→lenses, document weighting, multiverse, and validation scaffolding. A shared library stops drift and gives both papers one citable method implementation. Study I/O, prompts, and headline ℓ metrics must stay out so neither paper's specifics pollute the other.

## Detailed Description

### Boundaries

**In multilogue:** Unit/Phrase contracts; text helpers (`quote_support`, hashing, JSON); config loaders; Client protocol + Replay/Log clients + StageRunner; OpenAI/litellm optional adapters; generic extract (kind, template, sentinel, optional quote gate, yield/vocab); Embedder + frozen k-means + blind label/lens helpers; document weighting and bootstrap; multiverse enumerate + callback run + variance decomposition; κ/rank agreement; sheet sampling; evidence-pack shell; question-agnostic assess helpers.

**Out of multilogue:** PDF/docx parsers; grounds taxonomy; stories-follow-stories; coverage/cross-cutting; EMD/PERMANOVA; lens PPCA/σ²; study prompts; corpora; paper numbers.

### Structure

Modular split modelled on `dialogue_formats` (not a monolithic `address.py`). AAA lives under the `multilogue` namespace. Consumers depend on multilogue; multilogue never imports consumers.

### Fynesse

Cite Access → Assess → Address and “assess without the question”. Do not install or import the fynesse stub package as a library dependency.

## Implementation Plan

1. **Package scaffold** — `pyproject.toml`, `multilogue/` skeleton, tests layout, README
2. **Protocols, text, LLM** — port/generalise from dialogue_formats
3. **Extract, cluster, weight** — generic APIs
4. **Multiverse, validate, report** — callback multiverse + scaffolding
5. **Methodology docs** — `docs/methodology.md`, `docs/migration.md`
6. **Consumer backlog** — tasks to thin dialogue_formats and pub_dialogue (follow-on DO)

## Backward Compatibility

New package. Consumers adopt voluntarily; no breaking change until they switch imports.

## Testing Strategy

Synthetic units + FakeClient; no network or personal data. Pytest covers StageRunner fingerprint/replay, quote_support, weighting, multiverse enumeration/variance shares.
