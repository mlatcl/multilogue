## Summary

Move the **Bayesian PPCA soft mixture-weight** scheme, **σ² selection by mean Earth Mover's Distance** across multi-run lens mappings, and **document-level EMD (+ MDS / PERMANOVA / PERMDISP)** from `pub-dialogue` into multilogue as shared methodology (REQ-0008). Revise CIP-0001's "out of multilogue" list accordingly.

**Which requirements does this CIP address?** REQ-0008 (primary); extends the topic-space story of REQ-0003.

## Motivation

CIP-0001 deliberately parked "EMD/PERMANOVA; lens PPCA/σ²" in consumer Address so the first shared cut stayed thin and `ai-dialogue-formats` did not force-pull `pub-dialogue` specifics. That cut succeeded for extract→cluster→weight→multiverse shells, but it left the sophisticated soft-membership and transport layer — the material that makes the pub-dialogue pipeline distinctive — outside the citable library.

Those routines are already production code in `pub_dialogue.address` and `pub_dialogue.distance`, wired through `01a_clustering.ipynb` into notebooks 02–07. Promoting them stops drift, gives both papers one implementation to cite, and corrects the docs that currently tell authors to reimplement PPCA/EMD locally.

## Detailed Description

### What exists today (source of truth)

| Piece | Current home | Role |
|-------|--------------|------|
| `fit_lens_ppca` / `log_likelihood_ppca` / `compute_mixture_weights` | `pub_dialogue.address` | Per-lens PPCA Gaussian on member centroids; Bayes posteriors → soft weights |
| `sigma2_sweep_select` + `pairwise_mean_emd` | `pub_dialogue.address` | Log-spaced σ² grid; mean EMD of mixture rows across N lens runs; pick σ²* in effective-support band |
| `select_sigma2_in_band` | `pub_dialogue.multiverse` | Multiverse rule mirroring the constrained selection |
| `document_cluster_distributions`, `cosine_ground_cost`, `emd_distance_matrix`, `classical_mds`, `permanova`, `permdisp`, `run_document_distance_analysis` | `pub_dialogue.distance` | Document topic profiles → EMD → MDS / group tests |

EMD appears in **two** places:

1. **σ² stability** — ground cost between *lens means* across runs; mass on *mixture weights* per cluster.
2. **Document distance** — ground cost between *cluster centroids*; mass on *document×cluster shares*.

Both use POT (`ot.emd2`). Neither depends on technology labels or study prompts.

### Target multilogue layout

```
multilogue/
  soft.py          # PPCA fit, mixture weights, σ² sweep, pairwise_mean_emd
  distance.py      # document distributions, EMD matrix, MDS, PERMANOVA/PERMDISP
```

Keep `multilogue.cluster` for hard k-means + blind lens helpers (REQ-0003). Soft memberships are a separate Address layer that *consumes* centroids and mappings — same split as in `01a`.

Optional dependency: `pot` under `[project.optional-dependencies] distance` (or `soft`). Core install stays free of POT; importing EMD helpers raises a clear `ImportError` with install hint (match current `pub_dialogue` behaviour).

### Selection rule (preserve behaviour)

Default σ² grid: `np.logspace(-4, 2, 25)`. For each σ², compute mixture weights per run, then mean pairwise EMD. Among σ² with mean effective support in `[0.2, 0.6] × n_lenses`, pick minimum EMD; if the band is empty, fall back to unconstrained minimum EMD (as `AddressStage.sigma2_sweep_select` / `select_sigma2_in_band` do today). Do not invent a new rule without a multiverse sensitivity note.

### Boundary revision

**Remove from CIP-0001 "Out of multilogue":** `EMD/PERMANOVA; lens PPCA/σ²`.

**Still out:** PDF/docx parsers; grounds taxonomy; stories-follow-stories; coverage/cross-cutting; study prompts; corpora; paper numbers; technology-term filters; GenAI era windows.

## Implementation Plan

1. **API port** — module-level functions in `multilogue/soft.py` and `multilogue/distance.py`, signatures aligned with current `pub_dialogue` helpers (drop `AddressStage` coupling).
2. **Optional dep** — add `pot` to optional extras; document in README and getting-started.
3. **Tests** — port / rewrite `test_multiverse_sigma2.py` and `test_distance.py` patterns with synthetic data; assert constrained selection matches known fixtures.
4. **Docs + notebook** — concepts, cookbook, pedagogical cell(s).
5. **CIP-0001 note** — amend Out-of list; mark REQ-0008 Implemented when tests+docs land.
6. **Consumer backlog** — task in `pub-dialogue` to switch imports (Accepted → backlog only after this CIP is Accepted).

## Backward Compatibility

Additive for multilogue. No breaking change until consumers switch. Keep function names close to `pub_dialogue` (`compute_mixture_weights`, `sigma2_sweep_select`, `emd_distance_matrix`, …) so the thin-out is mechanical.

## Testing Strategy

Synthetic centroids and fixed lens mappings (no LLM, no corpus). Unit tests for PPCA log-likelihood shape, mixture rows summing to 1, σ² band selection, EMD symmetry / zero diagonal, PERMANOVA direction on planted group structure. Skip or xfail EMD tests when POT is not installed if the extra is absent in CI — prefer installing `pot` in the `dev` extra so CI always covers the path.
